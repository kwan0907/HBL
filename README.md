# HBL 多國產品格價計算器

這個版本已把「介面／計算功能」和「每個國家的產品價格」分開。原有搜尋、兩級價格、購物車、複製、VP 推薦、香港運費、套裝、三國格價、排序、匯率及字體大小功能均保留。

## 檔案結構

| 檔案 | 用途 | 平日是否要修改 |
|---|---|---|
| `data/hong-kong.js` | 香港產品與價格 | 香港改價時才改 |
| `data/taiwan.js` | 台灣產品與價格 | 台灣改價時才改 |
| `data/japan.js` | 日本產品與價格 | 日本改價時才改 |
| `config/countries.js` | 國家、貨幣、價格等級設定 | 新增國家時才改 |
| `config/comparison-map.js` | 各國同類產品編號配對 | 新增／移除格價配對時才改 |
| `app.js` | 共用計算及介面功能 | 一般改價不用碰 |
| `styles.css` | 共用外觀及 iPhone 排版 | 一般改價不用碰 |
| `index.html` | 網站主頁 | 一般改價不用碰 |

## 日後只改一個國家的價格

例如台灣改價，只開啟 `data/taiwan.js`，找產品編號後修改對應價格數字，再上載這一個檔案即可。香港、日本及主程式都不用修改。

## 日本中文短名

日本產品現在顯示成「中文短名｜日文原名」，例如：

- `F1 香草｜フォーミュラ 1 バニラ Non GMO`
- `深海魚油｜ハーバライフライン`
- `搖搖杯 400ml｜シェーカー 400ml`

`prod_name_zh` 是中文短名，`prod_name_ja` 是日文原名；想改中文叫法，只改同一件日本產品的 `prod_name_zh` 及 `prod_name` 前半部分即可。

## 新增第 4、5、6 個國家

1. 複製一個 `data/*.js`，改成新國家的代碼及產品價格。
2. 在 `config/countries.js` 加入一項國家、貨幣、價格等級及資料檔路徑。
3. 若要參與跨國格價，在 `config/comparison-map.js` 的同類產品加入該國產品編號。

國家按鈕、貨幣按鈕、排序按鈕及格價欄會自動產生；不需要再修改 `index.html` 或複製整個網站。超過手機寬度時可左右滑動，原有四級字體 `11 / 13 / 16 / 20` 沒有更改。

## 放回你現有的 GitHub

把本資料夾內所有檔案及 `config`、`data` 兩個資料夾上載到目前 HBL repository，取代舊的單一 `index.html`。請保留你 repository 現有的 `logo.svg`，並確保它和 `index.html` 在同一層。

> 拆檔後不能只上載 index.html；所有檔案及資料夾必須保留相同路徑。
